# Slidemoji 🎨

A sliding puzzle game built with React - designed as a hands-on learning project for mastering React concepts.

## What is This?

Slidemoji is an interactive sliding puzzle game where you:

- Click tiles adjacent to the gap to slide them
- Progressively unscramble the puzzle
- Track your time and moves
- Try to beat your best score!

But more importantly, this project is structured as a **comprehensive React tutorial** that teaches you React by building a real, fun project.

## How to Use This Tutorial

### Prerequisites

- Basic JavaScript knowledge (variables, functions, arrays, objects)
- Familiarity with ES6+ (arrow functions, destructuring, spread operator)
- HTML/CSS basics
- Node.js installed (version 14+)

### Learning Path

1. **Read [TUTORIAL_GUIDE.md](TUTORIAL_GUIDE.md)** to understand the structure
2. **Follow phases in order** - each builds on previous concepts
3. **Type all code yourself** - don't copy-paste! Muscle memory helps learning
4. **Experiment** - try modifying things to see what happens
5. **Use the reference docs** when you need a quick reminder
6. **Check troubleshooting guide** when stuck

### Philosophy

This tutorial is designed for **active learning**:

- We **explain concepts** with examples
- We **tell you what to build** to apply those concepts
- You **write the code yourself**
- You **learn by doing**, not just reading or watching
