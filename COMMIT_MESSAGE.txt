feat: Complete Firebase/Firestore integration with game state persistence

BREAKING: Board now requires initialBoard, savedBoard, and onMove props

This commit completes the full integration of Firebase Authentication and 
Firestore database for Slidemoji, enabling:
- Game state auto-save (resume games after closing)
- Trophy tracking (completedPuzzles with moves/time stats)  
- Dual streak system (play streak + win streak, Wordle-style)
- Archive puzzle support (past puzzles don't affect streaks)
- User preferences persistence (dark mode syncs across devices)

🔧 Database Configuration:
- FIREBASE_SETUP.md: Added security rules for puzzles collection
  - users collection: private, user-specific data (auth required)
  - puzzles collection: public read access (anyone can load puzzles)
- All users now get same puzzle boards for fair move/time comparison

🎮 Game State Persistence:
- Board.jsx: Complete rewrite for persistence integration
  - Accepts initialBoard prop from Firestore puzzle data
  - Accepts savedBoard prop to resume in-progress games
  - Calls onMove(newBoard) callback after each tile movement
  - Uses provided boards instead of scramblePuzzle() when available
  - Added detailed persistence comments explaining new behavior

- Game.jsx: Orchestrates persistence logic
  - Loads saved game on mount (resume mode) or starts fresh (new game mode)
  - Calls startPuzzle() on game start to update play streak
  - Auto-saves to Firestore on EVERY move (free tier supports 400+ DAU!)
  - Calls saveCompletion() on win to save trophy and update win streak
  - Handles restart by clearing saved state and re-calling startPuzzle()

- App.jsx: User data orchestration
  - Loads complete user document on sign-in (ONE read = all data)
  - Fetches today's puzzle from Firestore puzzles collection
  - Calculates highest earned difficulty for trophy badge display
  - Persists dark mode preference changes to Firestore

📊 Firestore Schema Implementation:
- Nested game state: gameState[puzzleId][difficulty]
  - Supports multiple puzzles at multiple difficulties simultaneously
  - User can play puzzle #63 on 3x3 AND 4x4 - both tracked separately

- Nested trophies: completedPuzzles[puzzleId][difficulty]  
  - Saves moves, time, startedAt, completedAt, fromArchive flag
  - UI shows highest difficulty trophy (4x4 > 3x3)

- Dual streak tracking:
  - currentPlayStreak: Consecutive days played (any attempt)
  - currentWinStreak: Consecutive days with at least one completion
  - Only daily puzzles update streaks (archive plays don't count)
  - Only first win of the day updates win streak
